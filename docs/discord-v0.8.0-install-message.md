RCLootCouncil_dibs v0.8.0 is now available. Everyone in the guild should install or update it before the next raid.

Download: https://github.com/TrueBrujah/RCLootCouncil_dibs/releases/download/v0.8.0/RCLootCouncil_dibs-v0.8.0.zip
Illustrated guide: https://github.com/TrueBrujah/RCLootCouncil_dibs/blob/main/docs/INSTALLATION.md

1. Download the ZIP. In Battle.net, select **World of Warcraft** > gear >
	**Show in Explorer**.
2. Open `_retail_\Interface\AddOns` (not a Classic folder).
3. Extract or replace `RCLootCouncil_dibs` directly inside `AddOns`. Check that
   `RCLootCouncil_dibs.toc` is directly inside the folder; avoid a double folder.
4. Return to WoW. You do not need to close it; run `/reload` after replacing
   the files.
5. Run `/dibs status` and react with :white_check_mark: when installed.
