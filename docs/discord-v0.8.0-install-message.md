RCLootCouncil_dibs v0.8.0 is now available. Everyone in the guild should install or update it before the next raid.

Download: https://github.com/TrueBrujah/RCLootCouncil_dibs/releases/download/v0.8.0/RCLootCouncil_dibs-v0.8.0.zip
Illustrated guide: https://github.com/TrueBrujah/RCLootCouncil_dibs/blob/main/docs/INSTALLATION.md

1. Download the ZIP and close WoW.
2. In Battle.net, choose World of Warcraft > gear > **Show in Explorer**.
3. Open `_retail_\Interface\AddOns` (not a Classic folder).
4. Extract `RCLootCouncil_dibs` directly into `AddOns`.
5. Check that `RCLootCouncil_dibs.toc` is directly inside the folder; avoid a double `RCLootCouncil_dibs` folder.
6. Start WoW and enable the addon.
7. Run `/dibs status` and react with :white_check_mark: when installed.
