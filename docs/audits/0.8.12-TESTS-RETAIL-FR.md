## Repartir d'une installation Dibs vierge (facultatif)

Le script [Reset-DibsInstallation.ps1](../../scripts/Reset-DibsInstallation.ps1)
cible `E:\Games\World of Warcraft\_retail_`. Il retire le dossier addon Dibs et
ses fichiers SavedVariables `.lua`/`.lua.bak`, **pour tous les comptes et
personnages de ce Retail**, après copie vérifiée par SHA-256 hors de WoW.
Les sauvegardes internes Dibs font partie des données retirées et de cette copie.
RCLootCouncil, les autres addons et les réglages WoW partagés restent conservés.

Depuis la racine du dépôt, afficher d'abord la liste sans modification :

```powershell
.\scripts\Reset-DibsInstallation.ps1
```

Pour effectuer le nettoyage, **fermer complètement WoW**, puis :

```powershell
.\scripts\Reset-DibsInstallation.ps1 -Apply
```

La copie de sécurité et son manifeste sont conservés dans un sous-dossier daté
de `%LOCALAPPDATA%\RCLootCouncil_dibs\CleanupBackups`; le chemin exact est affiché.
Ne pas diffuser cette copie : elle contient les données privées de l'addon.
Une fois le nettoyage fini, réinstaller avec `.\scripts\deploy.ps1`, puis relancer
WoW. Le retour de données de guilde après synchronisation reste possible : ce
nettoyage est local, il ne remet pas les autres membres à zéro. Une installation
vierge ne valide pas la récupération canonique encore incomplète (T049/T036).
